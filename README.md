# Business Agent Command Router

A workflow automation interface for a connected business agent that routes incoming requests into CRM updates, email drafting, calendar booking, database lookup, and approval-controlled actions.

## Use Cases

- Lead qualification and meeting booking
- Customer record lookup and update requests
- Support response preparation
- Internal operations assistant workflows
- CRM, email, calendar, and database automation

## Run

```bash
npm install
npm start
```

## Files

- `src/main.jsx` - application interface
- `src/styles.css` - responsive styling
- `workflow-blueprint.json` - automation workflow structure
